# Model artifacts and limits

The exact 27 historical task checkpoints have not been recovered. Encoder
initializations and unrelated models are not substitutes. No checkpoint is
included, no untrusted pickle is executed, and no weights URL is promised.
This is a saved-output evaluation study; the repository supplies an executable
measurement interface and permitted scalar results, not neural inference or
historical task-model retraining. Regression/ridge coefficients, if present in
other archives, are not segmentation-network weights or an annotation-free
measurement-quality model.
